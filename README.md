# NanoHunter
**מערכת מודיעין סייבר לחוקרי אבטחה, Bug Bounty ופנטסטרים**

NanoHunter הוא כלי מקומי (Local-first) שאוסף ממצאי אבטחה ממקורות ציבוריים, מסנן אותם לפי סוגי פגיעויות שבחרת, ומציג אותם בממשק נוח לחיפוש, שמירה וניתוח מהיר.  
המטרה היא לקצר זמן מחקר, לזהות הזדמנויות רלוונטיות מהר יותר, ולרכז פיד מקצועי אחד במקום לעבור בין עשרות אתרים.

---

## מה הפרויקט נותן

- **פיד מרכזי בזמן אמת** ממקורות אבטחה מובילים (RSS/Atom).
- **סינון לפי קטגוריות פגיעות** (XSS, SQLi, SSRF, IDOR ועוד).
- **עמוד ייעודי ל־Medium Reports** לזיהוי Writeups ודוחות Bug Bounty.
- **סיכומי AI (אופציונלי)** באמצעות Anthropic לפי השפה שבחרת.
- **Bookmarks, חיפוש וייצוא ל־Markdown** לעבודה שוטפת ומעקב.
- **שמירה מקומית של נתונים** ללא תלות במסד נתונים חיצוני.

---

## דרישות מערכת

- Python `3.8+`
- חיבור אינטרנט למשיכת פידים
- מפתח Anthropic API (אופציונלי, עבור סיכומי AI)

> אין תלות בספריות חיצוניות – הפרויקט עובד עם ספריות ה־stdlib של Python.

## התקנה והורדה

### 1) שכפול הפרויקט

```bash
git clone <REPO_URL>
cd nanohunter
```

### 2) הרצת השרת

```bash
python server.py
```

### 3) פתיחת המערכת בדפדפן

```text
http://localhost:8888
```

---

## שימוש בסיסי

1. פתח את דף הבית וצפה בפיד הממצאים.
2. בחר קטגוריות פגיעות בדף ההגדרות.
3. השתמש בחיפוש, פילטרי זמן ומקורות כדי למקד תוצאות.
4. שמור פריטים חשובים ל־Bookmarks.
5. ייצא ממצאים ל־Markdown כשצריך תיעוד מהיר.

## הפעלת סיכומי AI

אפשר להפעיל AI בשתי דרכים:

### דרך הממשק
- עבור לדף **הגדרות**
- הדבק Anthropic API Key
- הפעל את מתג ה־AI ושמור

### דרך משתנה סביבה

#### Linux / macOS
```bash
export ANTHROPIC_API_KEY="sk-ant-..."
python server.py
```

#### Windows PowerShell
```powershell
$env:ANTHROPIC_API_KEY="sk-ant-..."
python server.py
```

> אם סיכום AI לא נוצר, בדוק שהמפתח תקין ושיש קרדיטים זמינים בחשבון Anthropic.

## מבנה נתונים מקומי

כל הקבצים נשמרים בתיקייה `data/`:

- `settings.json` – הגדרות משתמש
- `feeds_cache.json` – קאש פידים
- `bookmarks.json` – פריטים שמורים
- `daily_log.json` – צריכת סיכומי AI יומית
- `summary_*.json` – קאש לסיכומים לפי פריט
